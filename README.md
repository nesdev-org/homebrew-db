# Homebrew Hub - NES games database

JSON and asset database for **NES** homebrew entries on [Homebrew Hub](https://hh.gbdev.io). This is one of several platform-specific database repositories that feed Homebrew Hub - see the [full list of databases](https://github.com/gbdev/homebrewhub/blob/main/DATABASES.md).

Propose additions, improvements, and fixes to the entries metadata values (and the releases) here.
